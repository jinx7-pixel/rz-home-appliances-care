# RZ Home Appliances Care

RZ Home Appliances Care is a home appliance repair service website with a customer repair-request form and an admin dashboard for managing service requests.

## Features

- Appliance repair request form
- Request ID generation
- Email notifications
- Admin authentication
- Admin request management
- Search and filtering
- Request status management
- Customer review system
- Responsive design
- Security headers and request validation
- Rate limiting and idempotency protection

## Tech Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express
- Database: PostgreSQL
- API validation: Zod
- Database toolkit: Drizzle
- Deployment: Replit

## Environment Variables

Create a local `.env` file using `.env.example` as a reference.

Never commit `.env` or production secrets to Git.
